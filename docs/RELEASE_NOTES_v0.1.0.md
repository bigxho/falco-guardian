# FALCO Guardian v0.1.0 — Starter Release

FALCO Guardian v0.1.0 is the first public starter release of the project.

It provides the initial foundation for a free and open-source defensive security platform focused on local visibility, Linux telemetry, detection, incident-oriented monitoring, and minimal public exposure.

## Included in v0.1.0

- Python detection/runtime foundation
- brute-force detector
- port-scan detector
- anomalous-login detector
- potential-exfiltration detector
- authentication-log monitoring
- eBPF collector and loader source
- starter web dashboard
- YAML configuration
- systemd service definitions
- installer and dependency manifest
- English documentation

## Release Status

This release is intended as a **starter for development and authorized defensive testing**. It should not yet be treated as a fully hardened production security appliance. APIs, configuration, detection logic, packaging, and deployment procedures may evolve rapidly.

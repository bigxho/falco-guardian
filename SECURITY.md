# Security Policy

## Supported Versions

FALCO Guardian is currently an early-stage open-source project. Security fixes are applied to the latest development line and the latest tagged release when practical.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| < 0.1 | No |

## Reporting a Vulnerability

Please do **not** publish exploitable security vulnerabilities in a public GitHub issue.

For the initial project stage, contact the maintainer through the GitHub profile associated with this repository and request a private reporting channel. GitHub Private Vulnerability Reporting may be enabled for the repository after publication.

When reporting a vulnerability, include:

- the affected component and version;
- a concise description of the issue and its security impact;
- reproducible steps or a minimal proof of concept when safe to share;
- relevant logs with credentials, private keys, tokens, personal data, customer data, and internal addresses removed;
- any suggested mitigation, if known.

Please allow reasonable time for investigation and remediation before public disclosure.

## Scope

FALCO Guardian is intended for defensive monitoring of systems and networks that the operator owns or is explicitly authorized to administer. Security reports about the FALCO Guardian codebase are welcome. Reports concerning unauthorized access to third-party systems are outside the project's scope.

# Changelog

All notable changes to FALCO Guardian will be documented in this file.

The project uses semantic versioning where practical during its early development phase.

## [0.1.0] - 2026-09-28

### Added

- Initial public starter release of FALCO Guardian.
- Python detection engine and runtime components.
- Detectors for brute-force activity, port scanning, anomalous login activity, and potential exfiltration patterns.
- Linux authentication-log watcher and supporting core modules.
- eBPF collector source and loader components.
- Web dashboard starter interface.
- YAML configuration baseline.
- systemd service definitions.
- Installation script and Python requirements.
- English project documentation.
- GNU GPL v2 licensing documentation.
- Security, contribution, code-of-conduct, and repository hygiene files for public GitHub development.

### Status

This is an early starter release intended for development, testing, and authorized defensive-security experimentation. Interfaces and configuration may change before a stable release.
